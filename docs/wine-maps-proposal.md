# SOMM100 · Wine Maps 实施方案

目标：把地图作为学习工具，让产区、葡萄园、酒庄和酒款相互连接。先做好 Alsace、Champagne、Burgundy，再按资料质量扩展，不一次铺满全球空地图。

## 用户流程

国家 → 产区 → 子产区 / 村庄 → 葡萄园 → 酒庄 → 酒款。点击地图点位或左侧目录，都打开同一张知识卡。手机上用地图＋底部卡片，避免逐层打开新页面。每张卡提供概览、葡萄与风格、图片、来源、相关练习；酒款可关联自己的 Tasting Notes。

## 三步交付

1. 地图资料库：整理现有地图和官方地图，标注来源、日期、比例、用途和使用范围。可放大、拖动，保留图例。第一批以已确认内容为准；当前上线的经纬度定位示意不算完整产区地图。
2. 学习图层：接入核实后的 GeoJSON 边界、村庄/酒庄坐标，支持葡萄品种、分级、海拔/坡向、土壤等图层。每层独立标注来源和版本。只有点位的资料不推导边界；没有可复用授权的官方地图采用外链。
3. 训练模式：隐藏标签、点选产区、村庄与分级匹配、葡萄园归属、酒庄和酒款关联；做错后返回同一知识卡。按 Intro/Certified、AS、MS 选择深度。

## 数据和技术

复用现有 knowledge-node IDs。MapAsset 保存原图/链接/来源/授权/版本；GeoFeature 保存坐标或边界及其来源；MapLayer 控制图层；MapExercise 关联题目与 featureId；TastingReference 仅关联本机品鉴记录，未来再接账号同步。

优先采用无需 WebGL 的图片地图与热点，再评估矢量地图方案。地图底图、内容图层、教学资料必须分开，防止更换服务商时重做内容。在中国大陆网络和目标鸿蒙/iOS 手机上测试加载、缩放、标签可读性后再选在线底图，不直接依赖当前已失败的外部嵌入服务。

## 首批验收

- 每张地图有来源和日期，法定边界与教学示意明确区分。
- 地图点位与目录显示相同知识卡；外链可辨认。
- 390px 手机可缩放、移动并返回上级，不误触。
- 练习判定基于已核实边界/关联，不按模糊图片猜测。
- 不凭空新增葡萄园、酒庄坐标或版权地图。
