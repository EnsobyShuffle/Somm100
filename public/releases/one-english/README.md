# ONE English · V0.1

独立英语学习 App。采用响应式网页 / PWA，不属于 SOMM100。

## 已有功能

- 首页：30 / 60 / 120 分钟学习计划（词汇、句子、阅读、口语训练量随目标调整）
- 词汇：150 条真实英文词汇和实用表达、例句、朗读、主动回忆、基于记忆结果的间隔复习、收藏和检索
- 句子：30 句常用表达、中英文解释、跟读、每日学习计数
- 阅读：14 篇 A0—B1 文章，英文朗读、逐词词库查询、中文导读、理解测验
- 口语：12 个常见生活/旅行/工作/餐厅模拟对话场景、语音输入（受浏览器支持限制）、12 张 IPA 基础发音卡
- 成长：每日记录、连续练习、复习数量、阅读/对话完成情况、最近一周小图表、数据导出/导入
- 无需注册的离线练习模式；安装为手机桌面 App 的 PWA 资源
- 已预留可选的服务器端真实 AI 自由对话接口，**未配置服务器与模型密钥时不声称“AI 已开通”**。

## 方式一：自己体验

打开 `ONE_English_Standalone_v0.1.html`（下载包外单独提供）。仅一个 HTML 文件，内嵌课程数据、CSS、JavaScript。推荐使用最新版 Chrome 或 Edge；移动浏览器从文件打开时可能限制语音权限或本地存储。

## 方式二：发送给朋友使用（推荐）

1. 将 `ONE_English_Website_v0.1.zip` 下载保存到电脑。
2. 进入 https://app.netlify.com/drop ，上传该网站 ZIP 或解压后的文件夹。
3. 获取一个 HTTPS 网站地址，把地址发给朋友。网页版可以直接在手机使用；支持 PWA 的浏览器可选择“添加到主屏幕”。

**说明：** Netlify 的静态发布只能运行词卡、阅读、场景规则对话和本机进度等前端功能；它不会自动运行 `server.mjs` 或提供真实 AI 模型。为真实 AI 部署需要单独的 Node 服务器和合法 API 额度。

## 方式三：可选真实 AI 教练（开发者）

需要 Node.js ≥20。在完整源码目录中运行：

```bash
OPENAI_API_KEY='你的服务端密钥' AI_ACCESS_CODE='仅分享给测试者的访问码' npm start
```

默认端口 3000（也可通过 `PORT` 指定）。然后访问 `http://localhost:3000`，该 Node 服务器同时托管网页与 `/api/chat`。服务器使用 Responses API，参考 `server.mjs`。可以用 `OPENAI_MODEL` 指定经验证有权访问的模型。

**安全须知：** 不要把密钥粘贴到网页、截图、聊天或打包进文件。当前 Node 后端只是测试用的基础版本，不含成熟的账户、计费配额、反滥用和用户云端存储功能；如要公开运营，须增加身份验证、风控、日志隐私策略及服务端持久化。

## 版本限制

- **未正式上线公共网址**；目前提供的是经过基本交互测试、可自行打开或发布的 MVP。
- 离线情景练习是规则引导而非 LLM；真实 AI 自由对话需安全连接。
- 单词库和阅读规模是首版种子内容，不是完整英语课程；更高级别需要继续补充与审校。
- 朗读使用设备的 Web Speech 语音合成功能；听写/语音识别可用性和识别质量取决于浏览器、设备及语音服务，不能把匹配率当作发音评分。
- 没有服务器账号同步；数据存在各浏览器的 localStorage。更换设备请先导出 JSON 再导入。
- 今天学习时长是**计划值**；完成度按模块任务统计，不是假装已经用满指定时间。活跃时间另行粗略计时。
- 法语等语言的资料结构已预留，但目前只提供 English 内容。
